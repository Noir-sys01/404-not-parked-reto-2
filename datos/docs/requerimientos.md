# Requerimientos

## Funcionales
| ID | Requisito |
|---|---|
| RF01 | Registrar incidentes. |
| RF02 | Obtener ubicación por GPS. |
| RF03 | Marcar ubicación en el mapa. |
| RF04 | Seleccionar tramo vial. |
| RF05 | Clasificar obstrucción y actor. |
| RF06 | Registrar referencia opcional, fecha y hora. |
| RF07 | Adjuntar foto opcional anonimizada. |
| RF08 | Validar y guardar reportes. |
| RF09 | Consultar tablero y marcadores. |
| RF10 | Visualizar concentración mediante mapa de calor. |

## No funcionales
| ID | Requisito |
|---|---|
| RNF01 | Usabilidad: registro sencillo. |
| RNF02 | Rendimiento: objetivo de registro inferior a 30 segundos, por medir. |
| RNF03 | Compatibilidad con navegadores modernos. |
| RNF04 | Privacidad: ocultar placas y rostros antes de guardar. |
| RNF05 | Adaptabilidad a móviles y computadores. |
| RNF06 | Código organizado y documentado. |
| RNF07 | Contraste y legibilidad adecuados. |
| RNF08 | Validación e integridad de datos. |
| RNF09 | Facilitar ampliaciones futuras. |
| RNF10 | Optimizar imágenes; la captura indica máximo 800 px. |

Son requisitos, no certificaciones de cumplimiento.
